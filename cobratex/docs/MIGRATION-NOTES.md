# ملاحظات الدمج

**محفوظ كما هو من جي تك:** كل `backend/src/modules/*`، الترحيلات 0001–0035، الاختبارات الأصلية، مسارات الواجهة وهوكات البيانات وصفحات الميزات (`frontend/src/features/*`)، المعرّفات وتدفق البيانات. صفحة لوحة التحكم حُفظ منطق بياناتها حرفيًا وتغيّر العرض فقط.

**مأخوذ من الهدى:** الهوية البصرية (Navy/Gold، Cairo/Tajawal) مُطبَّقة عالميًا عبر إعادة تعريف مقياس ألوان Tailwind؛ الشريط الجانبي المجمَّع والشريط العلوي ومؤشر السحابة؛ بطاقات KPI والرسم البياني؛ نظام الإضافات بمانيفست؛ إدارة التحديثات/الإعلانات/الترخيص (بدل Firebase).

**إضافات جديدة:** الهوية المركزية `brand.json`، حارس التحكم عن بُعد + لوحة المطور (ترحيل 0036)، RLS (0037)، `scripts/fix-aliases.js`، إعداد SSL/Pool لـ Supabase، نقطة دخول Vercel Serverless.

**إصلاح في أصل جي تك:** ناتج `tsc` كان يحتفظ بمسارات `@/…` فيفشل `node dist/src/server.js` (أمر Docker/Render الأصلي). عولج بـ `scripts/fix-aliases.js` ضمن `npm run build`.

**غير منقول عمدًا:** إضافات الهدى الزراعية (مفرش، فراولة، HR…) لأنها مرتبطة ببيانات IndexedDB المحلية وليست جزءًا من هندسة الإضافات. يمكن إعادة كتابتها كإضافات فوق `ctx.api` عند الحاجة.
