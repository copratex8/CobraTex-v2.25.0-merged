# فحص دخان للواجهة (متصفح آلي)
يفتح كل مسارات `App.tsx` (~110) في Chromium ببيانات وهمية ويرصد الانهيارات (PAGEERROR).
**مهم:** هذا فحص «انهيار» لحالة المستأجر الفارغ — لا يتحقق من الأرقام ولا التنسيق (Tailwind غير مُبنى فيه) ولا من الخادم الحقيقي.
على جهاز فيه npm حقيقي الأفضل تشغيل `npm run dev` للواجهة مع الخادم الفعلي بدل هذه البدائل.
الاستخدام (بيئة بلا مستودع npm): `NODE_PATH=<node_modules فيها react+esbuild+playwright>`:
`bash build.sh && PW=playwright node run.cjs` (نفّذ `node genshapes.cjs` أولًا لتوليد `shapes.json` من أنواع الواجهة).
`shims/` بدائل مبسّطة لـaxios وreact-router-dom وreact-query. `fixtures*.json` ردود حقيقية الشكل ولّدتها الخدمات الفعلية (`fixtures-from-services.ts`).
آخر نتيجة (2.21.1): 90/110 مسارًا بلا أي خطأ؛ 20 صفحة (نسيج قديمة + كشوف الحساب + النسخ الاحتياطي) تحتاج ردودًا غنية — غير محسومة.
