# نسخة سطح المكتب غير المتصلة (Electron + خادم وقاعدة بيانات مضمَّنة)

**ما هي؟** تطبيق Windows يضمّ الخادم وPostgreSQL المضمَّن داخل الحزمة: يعمل على جهاز **بلا إنترنت وبلا أي خدمات سحابية**. تُبنى بـ `.github/workflows/build-exe.yml` (أو `build-exe.bat`).

**متى تستخدمها؟** لعملاء المصانع ذوي الاتصال غير المستقر. الوضع الافتراضي لباقي العملاء هو الـPWA السحابي + القشرة الخفيفة `desktop-shell/` (تفتح التطبيق المستضاف فقط، بلا كود أعمال).

**وضع المصادقة:** تعمل دائمًا بوضع `legacy` (لا Supabase). لا ميزات جديدة تُضاف هنا؛ تُبنى من نفس `backend/` و`frontend/`.

**الإيقاف النهائي (اختياري):** عندما لا يبقى عميل على نسخة مضمَّنة، جرّب الـPWA على أجهزتهم أسبوعين، احتفظ بنسخة أرشيفية من آخر إصدار، ثم احذف المجلد وملف `build-exe.yml`.
