# لوحة المطور الخارجية (Remote Control Plane)

تطبيق ثابت منفصل (`developer-panel/`) تنشره أنت وحدك، لا يراه العملاء. يتحكم عن بُعد بالنظام عبر `/api/developer/*`.

## ما تستطيع فعله
- **إيقاف/تشغيل المنصة كلها** (زر رئيسي) مع رسالة تظهر للمستخدمين.
- **إيقاف/تشغيل عميل بعينه** (Tenant) دون التأثير على غيره، مع رسالة خاصة (مثل «متأخر السداد»).
- **إشعارات شاشة تسجيل الدخول**: عنوان + نص + درجة (معلومة/نجاح/تنبيه/عاجل)، لكل العملاء أو لعميل محدد، بجدولة بداية ونهاية، وإخفاء/حذف، مع معاينة حيّة.
- **سجل تدقيق** لكل أمر تحكم.

## كيف يعمل الإيقاف (إنفاذ حقيقي من الخادم)
حارس `platformGuard` يسبق كل مسارات `/api`: إن كانت المنصة أو عميل المستخدم موقوفًا يُرجع **503 + `code: SERVICE_SUSPENDED`** + رسالتك، ويشمل تسجيل الدخول وتجديد الجلسة. الواجهة تعرض شاشة «تم إيقاف الخدمة» وتعطّل زر الدخول. يبقى متاحًا دائمًا: لوحة المطور، حالة المنصة العامة، `/health`، `/system/*`، `/bootstrap`. الحالة مخزّنة مؤقتًا 10 ثوانٍ فيسري الإيقاف خلال ≤10 ثوانٍ. لو تعذّرت قراءة الحالة يُسمح بالطلب (fail-open) حتى لا تُعطّل طبقة التحكم النظام نفسه.

## الإعداد
1. في الباك إند ضع `DEVELOPER_SECRET` (12+ حرفًا؛ بدونها تبدو المسارات غير موجودة 404). اختياريًا `DEVELOPER_JWT_SECRET` لتوقيع جلسة اللوحة (8 ساعات).
2. `npm run migrate` (الترحيل `0036_platform_control`).
3. عدّل `developer-panel/config.js` → `apiBase`، وانشرها كمشروع ثابت مستقل (أو افتح `index.html` محليًا).
4. ادخل بكلمة مرور المطوّر. محاولات الدخول محدودة (8 كل 15 دقيقة).

## الأمان
- مصادقة المطوّر مستقلة تمامًا عن مستخدمي العملاء (توكن العميل لا يفتح مسارات المطوّر، وبالعكس).
- اللوحة تخزّن الجلسة في `sessionStorage` فقط. ضع اللوحة على نطاق غير معلن، وكلمة المرور طويلة.
- نشر اللوحة علنًا آمن نسبيًا (كلمة المرور + تحديد المحاولات)، لكن يُفضَّل إخفاء رابطها.
- الإيقاف يمنع الوصول لا يحذف البيانات؛ التشغيل يعيد كل شيء فورًا.

## التراخيص (2.22.0)
قسم «🔑 التراخيص» في اللوحة يتحكم لكل عميل بـ:
| الخيار | القيم |
|---|---|
| النوع | تجربة (14 يومًا) • شهري • سنوي • دائم • مخصص (بتاريخ انتهاء). اترك «ينتهي» فارغًا ليُحسب تلقائيًا من تاريخ البدء |
| مهلة السماح | 0–365 يومًا بعد الانتهاء بكامل الصلاحيات مع شريط تنبيه أحمر |
| بعد المهلة | **قراءة فقط** (يرى بياناته ويطبع ويصدّر ولا يُدخل) أو **إيقاف كامل** |
| الربط | بلا ربط • بنطاق (`app.example.com` أو `*.example.com`) • بجهاز (يُسجَّل أول N أجهزة تلقائيًا) • نطاق + جهاز |
| الحدود | أقصى مستخدمين / فروع / أجهزة (فارغ = بلا حد) |
| التمديد | +شهر / +3 أشهر / +سنة (من الانتهاء الحالي إن كان مستقبليًا وإلا من اليوم) |
| الأجهزة | عرض وتسمية وإلغاء وحذف (الحذف/الإلغاء يحرر المقعد) |

- **بلا ترخيص** = بلا قيود (العملاء القدامى). اضبط `LICENSE_REQUIRED=1` على الخادم ليُرفض من لا ترخيص له.
- الإنفاذ في الخادم (`licenseGuard`): 402 للانتهاء، 403 للنطاق/الجهاز. الواجهة تعرض شريطًا أو تحجب الشاشة حسب الحالة.
- معرّف الجهاز = رمز عشوائي في متصفح المستخدم (`cobratex_device_id`)؛ مسح بيانات المتصفح يُنتج «جهازًا جديدًا» فيستهلك مقعدًا حتى تحذف القديم من اللوحة.
- **حدود الحماية بصراحة:** الربط بالنطاق يعتمد ترويسة Origin التي يرسلها المتصفح (لا يحمي من أدوات سطر الأوامر)، ومن يملك الكود ويستضيفه بنفسه يستطيع إزالة الفحص. الحماية الأساسية هي العقد؛ هذا طبقة تشغيلية تمنع النسخ العارض وتُدير الاشتراكات.
