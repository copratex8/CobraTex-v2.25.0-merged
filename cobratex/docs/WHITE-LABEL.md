# الهوية وإعادة البيع (White-label)

كل شيء في ملف واحد: **`frontend/public/brand.json`** (الاسم، الشعار، الألوان، اسم الشركة، الدعم، حقوق التطوير، `defaultTenantId`).
- بعد التعديل نفّذ `npm run brand:apply` (يزامن `manifest.webmanifest` و`index.html`)، أو أعد النشر (الأمر ضمن `npm run build`).
- على استضافة قائمة يكفي استبدال `brand.json` وحده لتتغير الهوية فورًا بلا إعادة بناء (الألوان والاسم والشعار وحقوق التطوير).
- الشعار: `logoUrl` (الشعار الدائري/الرمز) و`logoFullUrl` (الشعار الكامل على الدخول) داخل `public/brand/`. الشعار الحالي هو لوجو كوبرا تكس المعتمد. حدّث أيضًا `icon-192/512.png` و`favicon.png` لأيقونة التثبيت.
- حقوق التطوير «تم التطوير بواسطة شركة حي تك - جميع الحقوق محفوظة» تظهر في تذييل الصفحات والشريط الجانبي وشاشة الدخول وصفحة الإعدادات. `developer.showCredit` يخفيها — قرارك أنت كمالك للترخيص، لا العميل.

## رقم هاتف المطوّر
يُضبط في `developer.phone` داخل `brand.json` (الافتراضي 01014868778) ويظهر بجانب سطر الحقوق في الشريط الجانبي والتذييل وشاشة الدخول ولوحة المطوّر وشاشة إعداد الـexe. اتركه فارغًا لإخفائه.

## عدة عملاء بهويات مختلفة على نشر واحد (2.23.0) — العميل يأخذ رابطًا فقط
الكود والخادم وقاعدة البيانات عندك؛ لكل عميل **رابط** (أو نطاقه الخاص) يعرض اسمه وشعاره وألوانه.
1. لوحة المطور ← «🏷️ العملاء» ← **إنشاء عميل جديد** (شركة + مالك + دليل حسابات + ترخيص اختياري + رمز قصير). تُعرض كلمة مرور المالك المولَّدة **مرة واحدة**.
2. افتح العميل ← **حفظ الهوية**: الاسم عربي/إنجليزي، الشعار (رابط `https://` أو مسار `/`)، الألوان الأربعة، الدعم، النطاقات الخاصة.
3. **نسخ رابط العميل** ثم أرسله له: `https://<واجهتك>/?c=<الرمز>`. أول زيارة تحفظ الرمز في متصفحه فيعمل التطبيق المثبَّت (PWA) بلا استعلام. حقل «معرّف المستأجر» يختفي من شاشة الدخول.
4. نطاق خاص (`erp.client.com`): أضفه في الهوية، ثم اجعله CNAME إلى استضافة الواجهة وأضفه كنطاق مخصص هناك. الخادم يحل العميل من اسم النطاق تلقائيًا.
5. **ثابت لا يتغير بهوية العميل:** حقوق المطوّر (`developer`) — الخادم لا يقبلها أصلًا والواجهة تتجاهلها.
6. **حد معروف:** اسم/أيقونة التطبيق عند «تثبيته» على الهاتف تأتي من `manifest` النشر نفسه (واحدة لكل نشر)؛ أما داخل البرنامج فكل شيء بهوية العميل. لأيقونة تثبيت مختلفة لكل عميل: نشر واجهة منفصل لذلك العميل (يتصل بنفس الخادم).
7. **إعادة ضبط كلمة مرور المالك / تعطيل مستخدم** من نفس البطاقة؛ إعادة الضبط تنهي كل جلساته فورًا.
