# مقارنة مع TechTex («موسى تكس») — مبنية على أسماء الشاشات فقط

**المصدر والحدود:** النسخة المرفقة برنامج ويندوز (.NET) لم أشغّله، وملف بياناته فارغ. اعتمدتُ على أسماء ملفات الشاشات والتقارير داخل ملف الرموز (pdb) وأسماء عناصر القوائم، أي **قائمة شاشات لا سلوكها**. لم أنسخ كودًا ولا بيانات. لا أعرف تفاصيل الحسابات داخل كل شاشة.

## ما يظهر من هيكله
ثلاثة أصناف مخزنية: **خيوط (Th)** و**قماش خام (Fab)** و**قماش مصبوغ/جاهز (Fin)**. لكل صنف: ترميز (أنواع، أرقام، ألوان، وحدات، موردون، عملاء، مخازن)، وارد بتكلفة، رصيد افتتاحي، تسوية جرد، تحويل بين المخازن، بيع، مرتجع. وفوقها: **تصنيع لدى الغير** (FabricMfg/FinMfg بتكاليف ومرتجعات)، **أمر صباغة بمتابعة وإقفال**، **طلبات العملاء وأوامرهم**، **تسعير**، **بيع بعملة**، **إعادة تقييم لوط**، **حظر موردين**، وسجل حركات. تقارير: كارت لوط، رصيد لوط وقيمته، وارد حسب المورد/المخزن، بيع حسب العميل/نوع الدفع، **فرق سعر البيع**، **عجز**، **هالك الخيط والقماش**، **خسارة المصبغة**، تفاصيل أوامر العملاء.

## التغطية في كوبرا تكس
| وظيفة | الحالة |
|---|---|
| وارد/افتتاحي/جرد/تحويل/بيع/مرتجع بالمخازن | موجود (النواة) |
| تصنيع لدى الغير + خسارة | موجود (التصنيع لدى الغير، التشغيل للغير) |
| أمر الصباغة ومتابعته وإقفاله | موجود (الصباغة) |
| بيع بعملة وسعر صرف | موجود منذ 2.5.0 |
| كارت اللوط وقيمة اللوتات | **أُضيف 2.8.0** |
| فرق سعر البيع عن القائمة | **أُضيف 2.8.0** |
| بيع حسب نوع الدفع (نقدي/آجل) | **غير موجود** — الفاتورة لا تحمل نوع دفع |
| حظر مورد | موجود في النواة (يُراجع ربطه بالشراء) |
| إعادة تقييم لوط (تعديل تكلفته) | **غير موجود** — يمس الأستاذ، يحتاج قرارك |
| تقرير العجز عن طلبات العملاء | جزئي (متابعة البيع والأوامر الحرجة) |
| ترميز ألوان/أرقام خيوط بصيغة المصنع | جزئي (مواصفات الأصناف والألياف) |
